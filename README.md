# Roadmap Back-end Python → Software Engineer

Roadmap completo para quem deseja sair do nível iniciante e evoluir até **Desenvolvedor Back-end Python / Software Engineer**.

## Conteúdo

O roadmap aborda:

* Python
* Programação Orientada a Objetos
* Algoritmos e Estruturas de Dados
* Git e GitHub
* HTTP e REST APIs
* SQL e PostgreSQL
* Django e Django REST Framework
* FastAPI
* Testes
* Docker
* Linux
* Redis e Celery
* CI/CD
* Cloud
* Arquitetura de Software
* Sistemas Distribuídos
* Segurança
* Performance

## Recursos

A página também reúne links para **documentações oficiais** das principais tecnologias estudadas.

## Funcionalidades

* Checklist interativo
* Barra de progresso
* Progresso salvo no navegador
* Dark/Light Mode
* Links oficiais de documentação
* Design responsivo
* Projetos práticos progressivos

## Objetivo

A ideia é fornecer uma trilha prática para desenvolver as habilidades necessárias para conquistar a **primeira vaga de Back-end Python** e continuar evoluindo profissionalmente.

> **20% teoria → 30% exercícios → 50% projetos**

**Estude. Pratique. Construa. Publique. Evolua.**
